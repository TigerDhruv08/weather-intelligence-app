# Weather Intelligence App

A responsive Weather Intelligence application built with React and Vite, powered by Open-Meteo public APIs, and deployed via Cloudflare Pages.

## Features
- **City Search:** Search weather data for any global location.
- **Current Weather & Forecast:** View real-time conditions and a 7-day weather forecast.
- **Interactive Charts:** Visual temperature and precipitation insights styled in modern high-contrast orange and charcoal themes.
- **Planning Recommendations:** Simple activity and travel guidance based on weather conditions.
- **Error Handling:** Graceful feedback when a city is not found or API requests fail.

## Data Sources
- **Geocoding API:** Open-Meteo Geocoding (`https://geocoding-api.open-meteo.com/v1/search`)
- **Forecast API:** Open-Meteo Forecast (`https://api.open-meteo.com/v1/forecast`)

## Deployment Pipeline
1. **App Prototype:** Built using Google AI Studio App Build.
2. **Version Control:** Connected directly from Google AI Studio to GitHub.
3. **Hosting:** Deployed automatically using Cloudflare Pages.
